A3.3.1 – SQL Language Types

DQL – Data Query Language
Used to retrieve data.
SELECT * FROM Students;
DML – Data Manipulation Language
Used to insert, update, delete.
INSERT INTO Students VALUES (1,'Ali'); UPDATE Students SET Name='Sara' WHERE ID=1; DELETE FROM Students WHERE ID=1;
DDL – Data Definition Language
Used to create/modify structure.
CREATE TABLE Students ( ID INT PRIMARY KEY, Name VARCHAR(50) );
DCL – Data Control Language
Used for permissions.
GRANT SELECT ON Students TO user1;

A3.3.2 – Queries Between Two Tables

Students (StudentID, Name)
Enrollments (StudentID, Course)
INNER JOIN Example:
SELECT Students.Name, Enrollments.Course FROM Students INNER JOIN Enrollments ON Students.StudentID = Enrollments.StudentID;

JOIN connects tables using a common key.

A3.3.3 – Updating Data

UPDATE Example:
UPDATE Students SET Grade = 'A' WHERE StudentID = 1;
INSERT Example:
INSERT INTO Students (ID, Name) VALUES (2, 'John');
DELETE Example:
DELETE FROM Students WHERE ID = 2;

Always use WHERE to avoid changing all records!

A3.3.4 – Aggregate Functions

COUNT() – counts rows
SUM() – totals values
AVG() – average
MIN() – smallest
MAX() – largest
SELECT COUNT(*) FROM Students; SELECT AVG(Grade) FROM Students; SELECT SUM(Salary) FROM Teachers;
GROUP BY Example:
SELECT Course, COUNT(StudentID) FROM Enrollments GROUP BY Course;

A3.3.5 – Database Views

A VIEW is a virtual table based on a query.
CREATE VIEW TopStudents AS SELECT Name, Grade FROM Students WHERE Grade = 'A';
Benefits:
  • Security – hide sensitive data
  • Simplifies complex queries
  • Reusable

A3.3.6 – Transactions & Data Integrity

A transaction ensures operations complete fully or not at all.
BEGIN TRANSACTION; UPDATE Accounts SET Balance = Balance - 100 WHERE ID = 1; UPDATE Accounts SET Balance = Balance + 100 WHERE ID = 2; COMMIT;
ROLLBACK;
ACID Properties:
  • Atomicity
  • Consistency
  • Isolation
  • Durability

Transactions maintain data integrity.
