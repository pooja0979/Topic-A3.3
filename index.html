STEP 1: SQL Language Types

DDL – Data Definition Language

Used to define structure.

CREATE DATABASE School; CREATE TABLE Students (ID INT, Name VARCHAR(50)); DROP TABLE Students; ALTER TABLE Students ADD Grade INT;

DML – Data Manipulation Language

INSERT INTO Students VALUES (1,'Ali'); UPDATE Students SET Name='Sara' WHERE ID=1; DELETE FROM Students WHERE ID=1;

DQL – Data Query Language

SELECT * FROM Students;

DCL – Data Control Language

GRANT SELECT ON Students TO user1;

TCL – Transaction Control Language

BEGIN TRANSACTION; COMMIT; ROLLBACK;

STEP 2: Creating Database & Tables

Create Database

CREATE DATABASE School;

Create Table WITHOUT Constraints

CREATE TABLE Students( ID INT, Name VARCHAR(50), Age INT );

Create Table WITH Constraints

CREATE TABLE Students( ID INT PRIMARY KEY, Name VARCHAR(50) NOT NULL, Age INT CHECK (Age > 0) );

Modify Table

ALTER TABLE Students ADD Email VARCHAR(100); ALTER TABLE Students DROP Age;

Delete Table

DROP TABLE Students;

STEP 3: Queries (Detailed)

Basic SELECT

SELECT Name FROM Students;

WHERE Clause

SELECT * FROM Students WHERE Age > 16;

ORDER BY

SELECT * FROM Students ORDER BY Name ASC;

JOIN Example

SELECT Students.Name, Enrollments.Course FROM Students INNER JOIN Enrollments ON Students.ID = Enrollments.StudentID;

Types of JOIN

  • INNER JOIN
  • LEFT JOIN
  • RIGHT JOIN
  • FULL JOIN

STEP 4: Aggregate Functions

SELECT COUNT(*) FROM Students; SELECT AVG(Age) FROM Students; SELECT SUM(Salary) FROM Teachers; SELECT MIN(Age) FROM Students; SELECT MAX(Age) FROM Students;

GROUP BY Example

SELECT Course, COUNT(StudentID) FROM Enrollments GROUP BY Course;

STEP 5: ACID Properties

  • Atomicity – All or nothing
  • Consistency – Data remains valid
  • Isolation – Transactions don’t interfere
  • Durability – Data saved permanently
